# Recipe Radar 🍳

A full-stack web application that helps you decide what to cook based on the ingredients you have, and automatically generates a grocery list.

## Features
- Create and manage recipes
- Match recipes based on pantry ingredients
- Select recipes and generate an aggregated grocery list
- Persist grocery list with check-off support
- Seeded demo data for easy testing

## Tech Stack
**Frontend**
- React + TypeScript
- Vite
- React Router

**Backend**
- Node.js + Fastify
- Prisma ORM
- PostgreSQL

**Testing (planned)**
- Playwright (E2E)
